Configurar Firebase

Pega los datos de tu proyecto y descarga los archivos ya listos. Todo ocurre en tu navegador: no se envía nada a ningún servidor.

Dónde sacar los datos: Firebase → ⚙ Configuración del proyecto → Tus apps → app web </> → “Configuración del SDK”. Copia todo el bloque firebaseConfig.

firebase-config.js

Reemplaza el archivo del mismo nombre en tu carpeta.

firestore.rules

Reemplaza el archivo y publícalo en Firestore → Reglas → Publicar.

.firebaserc

Lo que sigue
  1. Activa Authentication → Correo electrónico/contraseña.
  2. Crea Firestore Database en modo de producción.
  3. Publica firestore.rules en la pestaña Reglas.
  4. Agrega tu dominio en Authentication → Configuración → Dominios autorizados.
  5. Sube la carpeta a Netlify (o firebase deploy --only hosting).
  6. Abre el sitio, crea al administrador y confirma el correo que te llega.
